# Hero Scatter: noise → trend line (ganti `@` drift)

## Goal

Ganti background hero yang sekarang (simbol `@` melayang, `HeroDither`) dengan scatter plot
"merapikan diri": titik acak berkumpul menjadi garis tren saat mouse mendekat atau halaman
di-scroll — visual literal dari headline "I turn data into decisions".

## Current context / assumptions

- Repo: static portfolio, tanpa build step. Root `C:/Coding SDT/Belajar/Website`.
- File sentuh: `index.html` (CSS inline, tidak perlu diubah), `app.js` (satu class diganti).
- Canvas sudah ada: `<canvas class="hero-river" id="hero-dither">` (`index.html:2320`),
  di dalam `section#hero` (100vh, relative, overflow hidden). CSS `.hero-river`

  Konten hero (`hero-content-new`) di `z-index: 10`. Tidak ada perubahan HTML/CSS.
- Class lama: `HeroDither` (`app.js:662-750`) — drift `@` + breathing opacity, warna
  charcoal `[28,28,28]` light / cream `[222,218,212]` dark via getter `_isDark`
  (baca `documentElement[data-theme]` per frame — pola ini dipertahankan agar
  theme-toggle mid-session tetap benar).
- Palet (`index.html:87-95,112-116`): `--bg #F7F5F2` / `#111110`,
  `--text #1C1C1C` / `#FFFFFF`. Titik abu-abu/hitam tipis, garis tren `var(--text)`.
- `prefers-reduced-motion` global baru dipakai page-transition (`app.js:3`) —

- `.hero-visual` / 3D canvas sedang `display:none` — jangan sentuh.
- Kartu dashboard mini (angka AKSA/HargaWatch) eksplisit NON-goal untuk plan ini (YAGNI).

## Architecture / proposed approach

Satu class `HeroScatter` gantikan `HeroDither` di `app.js`, id canvas tetap
`hero-dither`. Tiap titik punya posisi scatter acak + posisi target di garis tren
diagonal; parameter global `cohesion` 0..1 di-lerp tiap frame menuju target yang
dihitung dari jarak mouse ke tengah hero dan progress scroll. Render: titik (circle,
bukan glyph) + satu garis tren yang opacity-nya mengikuti cohesion. DPR-aware resize,
`prefers-reduced-motion` = satu frame statis.

```js
// ── HERO SCATTER: noise → trend line ────────────────────────────
// Titik acak berkumpul ke garis tren saat mouse mendekat / scroll.
class HeroScatter {
  constructor(canvas) {
    this.canvas = canvas;
    this.ctx = canvas.getContext('2d');
    this.cohesion = 0.15;
    this.targetCohesion = 0.15;
    this.mouseX = null;
    this.mouseY = null;
    this.time = 0;

    this._resize();
    this._populate();

    window.addEventListener('resize', () => {
      this._resize();
      this._populate();
    });

    // Canvas pointer-events:none → dengar mouse di section hero.
    const hero = document.getElementById('hero');
    if (hero) {
      hero.addEventListener('mousemove', (e) => {
        const r = this.canvas.getBoundingClientRect();
        this.mouseX = e.clientX - r.left;
        this.mouseY = e.clientY - r.top;
      });
      hero.addEventListener('mouseleave', () => {
        this.mouseX = null;
        this.mouseY = null;
      });
    }
    window.addEventListener('scroll', () => this._updateTarget(), { passive: true });
    this._updateTarget();

    if (window.matchMedia('(prefers-reduced-motion: reduce)').matches) {
      this.cohesion = 0.8;
      this._draw();
      return; // satu frame statis, tanpa rAF loop
    }
    this._tick();
  }

  get _isDark() {
    return document.documentElement.getAttribute('data-theme') === 'dark';
  }

  _resize() {
    const r = this.canvas.getBoundingClientRect();
    const dpr = Math.min(window.devicePixelRatio || 1, 2);
    this.W = r.width || window.innerWidth;
    this.H = r.height || window.innerHeight;
    this.canvas.width = Math.round(this.W * dpr);
    this.canvas.height = Math.round(this.H * dpr);
    this.ctx.setTransform(dpr, 0, 0, dpr, 0, 0);
  }

  _gauss() {
    // ~N(0,1) murah: jumlah 3 uniform
    return (Math.random() + Math.random() + Math.random() - 1.5) * 2;
  }

  _populate() {
    const { W, H } = this;
    const count = Math.max(40, Math.min(140, Math.floor((W * H) / 12000)));
    this.margin = Math.min(W * 0.12, 160);
    this.pts = [];
    for (let i = 0; i < count; i++) {
      const t = Math.random(); // posisi sepanjang garis tren
      this.pts.push({
        sx: Math.random() * W,          // scatter anchor
        sy: Math.random() * H,
        t: t,
        off: this._gauss(),            // offset tegak lurus garis (satuan spread)
        r: 1.2 + Math.random() * 1.6,
        a: 0.3 + Math.random() * 0.3,
        phase: Math.random() * Math.PI * 2,
        freq: 0.4 + Math.random() * 0.8
      });
    }
  }

  // Garis tren diagonal: kiri-bawah → kanan-atas, lewat belakang headline.
  _lineXY(t) {
    const x = this.margin + t * (this.W - 2 * this.margin);
    const y = this.H * 0.74 - t * this.H * 0.48;
    return [x, y];
  }

  _updateTarget() {
    const hero = document.getElementById('hero');
    const heroH = (hero && hero.offsetHeight) || window.innerHeight;
    const scrollBoost = Math.min(1, (window.scrollY || 0) / (heroH * 0.6));
    let mouseBoost = 0;
    if (this.mouseX !== null) {
      const dx = this.mouseX - this.W / 2;
      const dy = this.mouseY - this.H / 2;
      const d = Math.sqrt(dx * dx + dy * dy) / (Math.sqrt(this.W * this.W + this.H * this.H) / 2);
      mouseBoost = Math.max(0, 1 - d * 1.15);
    }
    this.targetCohesion = Math.max(0.15, scrollBoost, mouseBoost);
  }

  _tick() {
    this.time += 0.016;
    this.cohesion += (this.targetCohesion - this.cohesion) * 0.06;
    this._draw();
    requestAnimationFrame(() => this._tick());
  }

  _draw() {
    const { ctx, W, H } = this;
    ctx.clearRect(0, 0, W, H);
    const c = this.cohesion;
    const e = c * c * (3 - 2 * c); // smoothstep
    const spread = Math.min(W, H) * 0.09;

    const [r, g, b] = this._isDark ? [222, 218, 212] : [28, 28, 28];

    // Garis tren: muncul seiring cohesion.
    const [x0, y0] = this._lineXY(0);
    const [x1, y1] = this._lineXY(1);
    ctx.save();
    ctx.globalAlpha = 0.1 + 0.55 * e;
    ctx.strokeStyle = `rgb(${r},${g},${b})`;
    ctx.lineWidth = 1.5;
    ctx.beginPath();
    ctx.moveTo(x0, y0);
    ctx.lineTo(x1, y1);
    ctx.stroke();
    ctx.restore();

    // Titik: lerp scatter → garis + jitter yang menyusut saat rapi.
    for (const p of this.pts) {
      const [lx, ly] = this._lineXY(p.t);
      const jx = (Math.sin(this.time * p.freq + p.phase) * 6) * (1 - e);
      const jy = (Math.cos(this.time * p.freq * 0.8 + p.phase) * 6) * (1 - e);
      const px = p.sx + (lx + p.off * spread * 0.35 - p.sx) * e + jx;
      const py = p.sy + (ly + p.off * spread - p.sy) * e + jy;
      ctx.globalAlpha = p.a * (0.55 + 0.45 * e);
      ctx.fillStyle = `rgb(${r},${g},${b})`;
      ctx.beginPath();
      ctx.arc(px, py, p.r, 0, Math.PI * 2);
      ctx.fill();
    }
    ctx.globalAlpha = 1;
  }
}

const _scatterCanvas = document.getElementById('hero-dither');
if (_scatterCanvas) new HeroScatter(_scatterCanvas);
```

## Risks, tradeoffs, and open questions

- Geometri garis diagonal (bukan horizontal): sengaja lewat belakang headline
  agar "data → decisions" terbaca. Kalau terasa menabrak teks, satu baris ubahan:
  `_lineXY` → garis horizontal `y = H*0.5`, slope 0.
- Cohesion awal 0.15: hero tidak pernah kosong total (pengunjung langsung lihat
  ada sesuatu), tradeoff-nya momen "rapi penuh" kurang dramatis. Naikkan
  scroll divisor (`heroH * 0.6` → `* 0.4`) kalau mau payoff lebih cepat.
- Titik circle polos (bukan glyph `@`): cocok palet krem/hitam; kalau mau
  tekstur dither lama, ganti `arc` → `fillText('.', ...)` — satu baris.
- Perf: ≤140 titik + 1 garis per frame, trivial; DPR cap 2.
- Tidak ada perubahan SEO/OG/canonical/footer — jangan sentuh di task ini.
